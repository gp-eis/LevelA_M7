# American English phoneme audio

Prerecorded WAV files used by `js/letter-phonemes.js`.

## Regenerate placeholders

```bash
node scripts/generate-phoneme-wavs.js
```

## Replace with studio recordings

Keep the **same filenames**. Record clear American English isolated sounds (or download licensed packs) and overwrite the WAVs in this folder.
